One gitignore-style pattern per line, matched from the archive root. An included path must not sit inside an excluded folder: include the folder itself.

Excluded paths are not extracted, but still appear in the tree with the rule that excluded them.

How your code is handled

The archive is uploaded to this server, safely extracted to a private temporary folder, scanned, then deleted. Nothing is executed. File contents read: .gitignore files (to decide what to skip), package manifests, and, when “Map the architecture” is on, JS/TS/Python source, parsed in memory. Only names, paths, sizes, import paths and line numbers are kept, in server memory, never the code itself.
